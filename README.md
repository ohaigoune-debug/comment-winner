# 🎉 Comment Winner

سحب الفائزين من تعليقات Facebook و Instagram بسهولة.

## ⚙️ الإعداد

```bash
npm install
npm run dev
```

افتح: http://localhost:3000

## 🔑 المتطلبات

- Meta Access Token (من Facebook Developers)
- رابط منشور من Facebook أو Instagram

## 📝 ملف .env

```
META_ACCESS_TOKEN=your_token_here
NODE_ENV=development
PORT=3000
```

## 🚀 النشر على Render

1. ادفع إلى GitHub
2. على Render: اختر Web Service
3. أضف Environment Variables
4. Deploy!
